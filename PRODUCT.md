# Cottrell

Cottrell is an image-level electrode inspection workspace for materials scientists examining fresh manufacturing electrodes. It connects a fixed scientific model to original TIFF upload, real exploratory processing, human region review and evidence-linked results. The planning PRD and ARD are in the parent ChatGPT Cottrell workspace.

The local app runs on port 8501 with FastAPI on 8502. A verified exploration bundle gates new runs; provenance includes scientific artifact hashes and actual package versions. The official held-out result remains unchanged. Modal is used when authenticated; new exploratory runs can fall back to checksum-verified local CPU embeddings.

Eleven measured features can be compared with user-selected morphology criteria. The scientist's manufacturing/formation and future-service catalogs are separate investigation guidance, with missing evidence shown explicitly. They do not create calibrated defect probabilities, confirmed process blame, life predictions or lot release decisions. F12 / AR_VOID is unavailable in v1. Physical conversion is bound only to the specifically attested source hash.

Review suggestions use a versioned local threshold-proximity diagnostic alongside the unchanged engine mask. Original-coordinate crops and saved review evidence are source-bound. Results include native measurements, criteria, batch similarity, caveats, exact mask views, three analysis-layer planes, source downloads and CSV/JSON/current-view print export.
