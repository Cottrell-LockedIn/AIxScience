# Log: Phase C (classifier, held-out pipeline, freeze)

Owner instruction 2026-10-04: one model, fixed defaults, no alternatives; Phase A/B code and outputs unchanged.

## Frozen choices (committed before the 31-fold LOIO run)

1. Unit = image (n = 31: Batch_1 7, Batch_2 7, Batch_3 17). Inputs, read as committed by Phase B: `results/features_per_image.parquet` (F01–F11, scale 1.0) and `results/emb_per_image.parquet` (channel BSE, e000–e383). Tiles are never samples.
2. Per fit: `StandardScaler` on F01–F11 ⊕ `PCA(n_components=29, svd_solver="full")` on the raw mean-pooled BSE embedding (scores not rescaled); both fitted on that fit's training images only. Deviation: PCA(32) is impossible with 30 training images (centred rank ≤ 29); 29 is used in every fold and in the final fit.
3. Classifier: `LogisticRegression(C=1.0, class_weight="balanced", solver="lbfgs", max_iter=10000, random_state=0)`. In scikit-learn 1.9.1, L2 is the default penalty and 3-class lbfgs is multinomial (`multi_class` was removed).
4. Validation: leave-one-image-out, 31 folds; accuracy k/31; confusion matrix. The PR #9 tier needs a chance test: 1,000 image-label permutations of the whole LOIO (seed 0), p = (1 + #{perm acc ≥ obs}) / 1001. The chance level is also stated as majority 17/31.
5. Bet: `pred_batch` = argmax of the out-of-fold probability. It is always a batch. Confidence = that probability; margin = top − runner-up.
6. Tier (PR #9): `low` if p_max < 0.5, or LOIO permutation p ≥ 0.05, or OOD = outside. `medium` if 0.5 ≤ p_max < 0.75. `high` if p_max ≥ 0.75 and p < 0.05. Deviation from PR #9: the nearest-distance fallback is not used (the owner fixed one model), so if the model does not beat chance the LR bet stands with tier `low`.
7. Drivers: contribution_k = coef[pred_batch, k] × x_k, where x_k is a standardised F value or a PC score. Top 3 by signed contribution, i.e. the largest support for the bet. F features carry their Phase B status. PCs are named "embedding PC k" and tagged "acquisition and material not separable (Phase B residualisation)".
8. OOD flag (Phase B BSE geometry: L2-normalised 384-d vectors, Euclidean): E1(x, R) = 2·mean_r‖x − r‖ − mean_{r≠r'}‖r − r'‖, with R = Batch_3 minus x.
   - Band: the Batch_3 split-half null at the matched size 1 vs rest, i.e. each Batch_3 image vs the other Batch_3 images, 95/99 % quantiles (numpy linear). For a Batch_3 training image the band uses its 16 peers only.
   - Deviation: the Phase B 7-vs-10 band is a set-level statistic on a different scale from a single image.
   - `matches_known_batch` = E1 ≤ band99. Image label: `within_bounds` ≤ band95, `investigate` in (band95, band99], `outside_bounds` > band99. This never replaces `pred_batch`.
9. Acquisition: the 8 Phase B covariates per image vs the training p05/p95, flagged if outside. They are reported and are not model inputs.
10. Final model: the same pipeline fitted on all 31 images; coefficients in `results/v1/final_model.csv`. `qc heldout` refits from the committed inputs and stops if the coefficients differ by > 1e-9.
11. Held-out: `data/heldout/` is processed once at tag `v1-frozen` with `configs/v1.yaml` unchanged, BSE tiles embedded on Modal L4 (max_containers=10). Any later run is labelled exploratory.

## Results (LOIO run at e6046e6; frozen choices committed first at af87cd9)

- LOIO accuracy **18/31** (0.581; Wilson 95 % CI 0.41–0.74). Majority-class rate 17/31. Label-permutation p = 0.035 (1,000 permutations; median 12/31, 95th percentile 17/31). Balanced accuracy 0.465 (chance 0.333).
- Confusion matrix (rows = true, cols = predicted, order B1/B2/B3): B1 [2, 4, 1]; B2 [4, 2, 1]; B3 [0, 3, 14]. Collapsed from the same predictions: Batch_3 vs not-Batch_3 is 26/31. Batch_1 and Batch_2 are mostly confused with each other, which is consistent with Phase B finding no Batch_1–Batch_2 difference.
- Tiers: high 18 (14 correct), medium 5 (1 correct), low 8 (3 correct). OOD: 8 `outside_bounds` (Batch_1 5, Batch_2 2, Batch_3 1 = `ptg8lmto`), 23 `within_bounds`.
- Drivers: 73 of 93 top-3 slots, and 28 of 31 top-1 drivers, are embedding PCs. Phase B found that the embedding batch differences vanish after acquisition residualisation, so the bets may rest on acquisition rather than material. Every per-image JSON states this.
- Outputs: `results/v1/loio_predictions.csv`, `loio_summary.json`, `confusion_matrix.csv`, `final_model.csv`, `loio_images/<id>.json` (schema-valid).
- `qc heldout` dry-run (`0grcilhi`, `3806gxp0`, `4ih2ggld` copied to a temporary folder; Modal L4, max_containers=10): F01–F11 and BSE embeddings are identical to the training values. Covariates are identical except a 1-ULP difference in `nm_per_px_if_tag_true` (CSV round-trip). Two dry-run executions during implementation, total about $0.003 (`results/v1/MODAL_RUNS_v1.csv`). Dry-run scores do not count; those images are in the training set.
- Implementation deviations: the CLI gained `heldout --input-dir/--out/--dryrun/--exploratory` (the real run refuses unless HEAD is exactly `v1-frozen` with clean src/configs/schema and no existing `results/v1/heldout.json`). The schema now requires `closed_set.predicted_batch` and `confidence` for image subjects.
