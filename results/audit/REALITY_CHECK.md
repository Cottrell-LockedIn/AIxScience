# Reality check (S1-S5, v1 config `1bec114301c3`, git `c007beb`)

Figures: `reality_check_fractions.png`, `reality_check_artefacts.png`, `artefacts_by_batch.png`, `overlays/` (6 tiles, 2 per batch). Classes are grey-level classes 0/1/2; units are px; pixel size unconfirmed. No verdicts here.

1. Data: 31 images (Batch_1 7, Batch_2 7, Batch_3 17), 93 TIFFs; 27 images have BSE+ETD+Inlens, 4 have BSE+Inlens+SE; every image has an Inlens view (img_xgj4xftb_Inlens.tif was missing from the repo's Drive listing and was added from the shared folder). 2880 tiles (1024 px, stride 512), 960 of them BSE.
2. Class fractions (per-image mean over tiles): batch medians c0 = 0.099 / 0.091 / 0.102, c1 = 0.827 / 0.820 / 0.805, c2 = 0.087 / 0.089 / 0.095 (Batch_1 / 2 / 3). The largest gap between batch medians is 0.4-1.0x the median within-batch IQR, so **no batch separates on fractions beyond its own spread**.
3. Three images carry most of the class-2 spread: 4ih2ggld and 5n1q8atc (Batch_1) at c2 = 0.20-0.22 and r17byphk (Batch_2) at 0.16, roughly 2x the other 28 images (0.06-0.14).
4. Threshold sensitivity: scaling the per-tile multi-Otsu thresholds by 0.9 / 1.1 moves c2 by a median 0.041 / 0.022 and c0 by 0.009 / 0.015 per image, i.e. the +/-10 % error bars are as large as or larger than every between-batch gap.
5. Per-tile multi-Otsu is unstable on tiles without bright particles: upper threshold t1 ranges 47-90 (median 82); the 23/960 tiles with t1 < 60 report median c2 = 0.26 vs 0.08 elsewhere (corr(t1, c2) = -0.63; see overlay avn74qx1, t1 = 51, where class 2 outlines flake texture). Candidate for an S4 challenger (per-image thresholds or a floor on t1); v1 left as specified.
6. Artefacts: curtaining_score (BSE) and edge_charging (Inlens) do not separate batches (median gaps 0.8x and 1.1x the within-batch IQR). noise_sigma and sharpness (BSE) do: Batch_3 median noise 37.7 vs 46.2 / 44.1 (gap 2.8x IQR), and Batch_3 splits into a low-noise cluster (7 images, sigma 29.6-31.4) and a high-noise cluster (10 images, 37.6-45.6).
7. Images group by (height, XResolution tag): 15 groups, each with near-identical noise and sharpness, and 5 of them span two or three batches (e.g. height 2080 / tag 126998864/125 holds one image from each batch). This looks like acquisition sessions that cut across batch labels; it must be checked with Polaron (consultant C1) and means S7 needs artefact ablation plus a leave-one-group-out check, not only leave-one-image-out.
8. Contradictions with `docs/READ/Dataset First Look.md`: widths are 6960-7000 px, not a uniform 7000; the coloured edge line is in column 0 (20 files) as well as the right edge (18 files), the 8 px crop covers both; the resolution tag takes 13 distinct values that all round to 25.000 nm/px and was written by tifffile, so it is not microscope metadata.
9. Wall time (8 CPU cores): download ~3 min (93 files, 1.7 GB); audit 12 s; tiles 12 s; artefacts 44 s; segment 50 s; kpi + sensitivity + overlays 65 s; figures 3 s.
